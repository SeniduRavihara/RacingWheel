# 🖨️ 3D Models

Place your 3D printable STL files here.

## Suggested Parts to Print

| Part | Description |
|------|-------------|
| `wheel_hub.stl` | Center hub that mounts to shaft |
| `wheel_rim.stl` | Outer grip ring |
| `button_mount.stl` | Button panel holder |
| `mpu6050_bracket.stl` | Gyro module mounting bracket |
| `enclosure_box.stl` | Electronics box |

## Free Resources

- [Thingiverse](https://www.thingiverse.com/) — search "sim racing wheel"
- [Printables](https://www.printables.com/) — search "DIY racing wheel"
- [GrabCAD](https://grabcad.com/) — engineering-grade models

## Print Settings (PLA recommended)

| Setting | Value |
|---------|-------|
| Layer height | 0.2mm |
| Infill | 30–40% |
| Walls | 3 perimeters |
| Support | As needed |
